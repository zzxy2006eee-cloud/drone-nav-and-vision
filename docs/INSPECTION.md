# 单区域下视巡检

更新：2026-10-07。功能已接入代码与 Qt；已完成编译和离线检查，**尚未完成 ROS/Gazebo 飞行验收**。当前工具环境创建本机 TCP 监听返回 `PermissionError: Operation not permitted`，无法在此环境启动 ROS master。不要把离线路线检查称为仿真飞行通过。

## 1. 启动和操作

实验暂时不打开 Gazebo 图形界面，保留 Qt：

```bash
cd /home/d/robotproject/project0
# 终端 A
DRONE_SHOW_GAZEBO=0 bash start/start_gazebo.sh
# 终端 B
bash start/start_navigation.sh inspection
```

1. 在 Qt 预建地图中选出生位置、拖动朝向并确认，等待地图加载、定位健康。
2. 切换顶部“区域巡检”页，点“框选矩形”拖动鼠标；或“绘制多边形”，逐点选择后点“完成多边形”。
3. 使用本页独立的“巡检高度 地图Z”，默认1.2m。默认手动间距0.5m、速度0.5m/s；自动间距默认重叠20%。
4. 点“生成巡检路线”。计算在后台执行，预览后可调整方向/候选入口重新生成。修改参数后原预览不能直接开始。
5. 手动授权、ARM、起飞；健康 OFFBOARD 悬停后点“开始巡检”。
6. 无人机从当前位置连接区域入口，再沿条带扫描。可暂停、继续或取消；结束在最后安全位置 HOLD。

无预建地图、未确认初始位姿时，Qt 禁用巡检，后端也拒绝请求。巡检执行或暂停时占用普通导航入口，先取消巡检才能发送普通目标。不会自动授权、解锁、起飞或返航。

### 已知区域与分页

选区并填写参数，在“已知巡检区域”输入名称，点“保存为新区域”。支持加载、更新、删除和刷新，重名新增不会覆盖旧区域。加载只恢复多边形和参数，必须重新生成路线；不会自动起飞或扫描。执行/暂停期间禁止编辑区域库。

区域库按地图内容SHA256隔离；相同内容换路径仍可识别，修改地图文件后需重新加载。保存至 `start/inspection_regions/<摘要>.json`，原子写入、加锁，重启保留。最多256个区域/地图、名称64字符，可备份整个目录。区域保存与 `.dmap` 保存独立。

综合和巡检页共享一个地图渲染器，两页均有相机画面，只更新可见画面。切页不重建渲染器或停止任务；顶部状态、一键降落和事件栏公共。另见 [AI文本控制](AI_CONTROL.md)。

## 2. 地图与路线

地图仍是实时更新的共享三维体素，不新增二维控制地图。区域在 `map` 中定义，转换到当前控制 `odom`。扫描中心线固定高度，连接段可在既有飞行边界内进行三维安全寻路。

- 矩形与无自交多边形，3～64 顶点，最小面积 0.1 m²。
- 间距 0.1～5 m、速度 0.1～1.0 m/s、自动重叠率 0～80%。
- 自动方向比较 0～165°、每15°的候选，四种入口顺序；按长度/转场估计排序并尝试可达候选，不承诺求得全局最优任务。
- 条带按既有膨胀地图切分，转场先尝试切线连接贝塞尔曲线，再使用当前三维 A* 和平滑实现。
- 完整任务保存在管理器中，向控制端滚动提交默认前方最多12m、1800点的参考，EGO 保持原前方5m局部优化；按原几何截短窗口，不丢掉弯道换成捷径。
- 最多256条原始扫描行，覆盖网格最多200000单元，规划单次默认30秒墙钟预算；超限显示原因，不阻塞 Qt。

颜色：青色区域/条带、橙色全任务连接预览；黄色是全局节点正式参考，紫色是批准执行的 EGO 轨迹，绿色实际飞行轨迹。预览不是已批准执行轨迹。

中间滚动窗口标记为继续运动，最终窗口才启用停止/到达收敛。窗口更新不会重启整个 EGO 会话。暂时没有安全参考时，沿用既有等待与保护，不允许按显示中的不完整路径直接继续飞。

普通 A* 不得用入口到窗口末端的直线代替巡检条带。当前仍允许 EGO 为运动约束和避障偏离参考；覆盖统计依据实际相机采集，不假定显示路线就是实际覆盖。

## 3. 下视相机配置与覆盖

配置文件：[inspection.yaml](../src/drone_stack/config/inspection.yaml)。

| 参数 | 默认值 |
|---|---|
| 图像分辨率 | 640×480 |
| fx/fy | 381.36114963 px，对应当前仿真80°水平视场 |
| cx/cy | 320/240 px |
| 相机机体位置 | `[0,0,-0.15] m` |
| 光学坐标到机体旋转 | 配置中3×3矩阵，默认向下安装 |
| `surface_z_map` | 0 m，默认场景地面 |
| `coverage_resolution_m` | 0.10 m |
| `camera_timeout_s` | 0.5 s 仿真时间 |
| `keyframe_hz` | 1 Hz，按图像采集时间 |
| `completion_ratio` | 99% |

自动间距使用巡检地图 Z 和相机安装偏移，求图像投影在配置地面上的横向幅宽，再乘 `(1−重叠率)`。不能无条件把地图 Z 当成净离地高度。

配置是在启动时加载的；修改相机参数后需要重启程序。修改此文件不会自动修改 Gazebo 相机模型。后端核对 `/drone/down/camera_info` 与图像尺寸、焦距、主点，配置不符时拒绝开始或暂停任务。

实际覆盖用每帧采集时间对应的 FCU 机体位姿，匹配容差0.15秒，计入实际姿态、相机安装旋转，再与水平扫描地面求交。只在扫描阶段、相机与飞行健康时累计；入口、绕行、换行不直接累计。

覆盖图为绿色已覆盖、橙色待覆盖、红色规划障碍排除。障碍排除依据巡检高度处的安全地图；当前统计是**平面几何图像覆盖**，没有逐像素验证遮挡、图像清晰度、目标识别或设备表面高差，不等于缺陷检测成功。

## 4. 异常与任务状态

状态包括待选区、生成、预览就绪、入口/转场导航、扫描、换行/转向、重新连接、暂停、完成、部分完成、取消、失败。

- 新障碍：HOLD 后重新连接剩余条带，已完成段不重复派发；无法连接部分标漏扫。剩余全不可达时部分完成。
- 相机断流、时间失效或配置不符：暂停并 HOLD，保留任务，恢复后必须人工点继续。
- 地图 epoch 或对齐变化：暂停；需取消并重新生成。
- LIO/EKF/地图/EGO 导航中断：巡检暂停或终止，现有飞行管理器继续负责1秒HOLD、2秒降落和严重异常保护。不会由巡检代码覆盖已有降落。
- 巡检管理器心跳超过1秒仿真时间未更新：飞行管理器独立取消导航并HOLD，避免巡检节点卡住后继续沿旧参考飞行。
- 偏离任务参考超过0.75m：暂停；恢复时从实测位置重新连接剩余任务。
- 写入异常或记录队列满：黄色提示，停止新增记录，不因记录问题自行降落。
- 取消：清理巡检预览/覆盖显示并请求 HOLD；地图及既有数据文件保留。

Qt 的异常摘要提供编号、首次发生仿真时间、重复次数、原因、动作及下一步。警告/暂停/部分完成黄色，严重异常/失败红色。重复次数更新不刷事件日志，恢复事件保留在历史日志；红色任务失败本身不是降落命令。

只有所有可执行段处理完、覆盖达到99%且无未解决不可达条带，才显示完成；其余显示部分完成。暂停任务仅在本次运行内恢复，重启后不会自动续飞。

## 5. 记录与公共接口

任务开始后默认写入 `start/inspection_records/<时间>_<计划ID>/`：

- `plan.json`：区域、参数、相机、地图路径/epoch/对齐、方向与入口。
- `route.jsonl`：本次和恢复/绕行后的参考路线及阶段。
- `trajectory.jsonl`：实际地图位置、进度、阶段。
- `event.jsonl`：异常首次发生、变化、恢复。
- `down_<采集时间>.jpg` 与 `frames.jsonl`：1Hz原始下视关键帧、采集位姿、投影、条带编号。
- `summary.json`：结束/暂停时覆盖、漏扫与任务结果。

记录使用有界后台写入队列，不默认录完整 rosbag。记录失败会明确显示，不能把未写出的图像当作已保存数据。

| 接口 | 类型/用途 |
|---|---|
| `/drone/inspection/plan` | `PlanInspection`，异步规划请求，立即返回计划ID |
| `/drone/inspection/command` | `InspectionCommand`：start/pause/resume/cancel |
| `/drone/inspection/regions` | list/save/update/delete，当前地图已知区域库 |
| `/drone/inspection/status` | JSON String，阶段、覆盖、异常、参数与记录目录 |
| `/drone/inspection/exclusive` | Bool，执行/暂停期间普通目标互斥 |
| `/drone/inspection/draft`、`markers`、`coverage` | MarkerArray，区域草稿/任务预览/实际覆盖 |
| `/drone/execute_inspection_route` | `ExecuteInspectionRoute`，仅健康预建地图 OFFBOARD 接受控制参考 |
| `/drone/inspection_route` | 扩展 `GlobalRoute`，供统一全局节点接收参考意图 |

`GlobalRoute` 新增 inspection/continuous/revision/blocked；`StartPlanning` 新增 inspection/continuous。需要一起编译、重启 EGO 与 drone_stack，不能混用旧消息定义的运行节点。普通点到点默认仍是停止型路线。

区域巡检的计划/命令增加来源owner。AI来源包含Qt会话和请求ID，人工继续使用空来源接管；迟到AI取消不能取消被人工接管的同一计划。
