# 二维目标与路径显示

## 操作

1. 起飞后等待HOLD，点击“点选XY目标”，主视图切换为二维俯视。
2. 滚轮缩放二维图；左键选择任意XY位置（与雷达点云是否有点无关），Z使用右侧绝对ENU高度。
3. 选择后出现红色实心圆，服务端接受后锁定点选和相对目标按钮，直到到达/取消/保护停止。
4. 黄色线显示当前参考路线；发现新障碍而替代路线还在搜索时，显示已复核的安全前段。绿色线按MAVROS实际里程计记录，非控制目标或Gazebo真值。
5. 任务结束清除红点、黄色路线和绿色轨迹。悬停、取消和降落继续可用。

## 黄线的定义和边界

独立只读节点 `safe_global_path.py` 使用膨胀占用地图生成参考路线，发布 `/drone/global_path` 和 `/drone/global_path_markers`。黄色实线表示已观测自由路段，黄色虚线表示未观测参考路段；未知区域允许规划，已知膨胀障碍禁止穿越。目标落在已知膨胀障碍体素内时拒绝任务。搜索范围保持ENU [-8,-8,0.5]～[8,8,2.5]。

以0.25m格点有界3D A*连接目标，地图出现障碍时保留安全前段并搜索完整替代路线。无任务时停止重计算。黄线与EGO使用同一全局参考路线；未知路段不表示已确认安全，实际飞行由管理器审批EGO局部轨迹。

管理器先悬停转向，再检查执行前缀的已观测自由空间。前瞻至少3秒，并按任务速度、实际速度及定位/指令时延扩展制动裕量。遇到未观测区域进入内部SPACE_WAIT，保持NAVIGATING与同一Qt目标，连续发送悬停指令；收到新观测、速度<=0.1m/s、定位健康且等待至少2秒后重新规划。规划器心跳正常但5秒未生成轨迹时也保留目标重试；旧轨迹、通信/地图失效仍触发取消或原有降落保护。无法确认自由空间时可能持续等待，可用“悬停/取消目标/一键降落”结束任务。

“移动速度”范围0.1～1.0m/s，默认0.5、步长0.05。设置仅影响下一任务；管理器和EGO优化器缓存限值同步更新，内部转向/等待后的重规划沿用当前任务速度。规划速度是设定值，实际闭环速度仍受轨迹可行性及PX4控制响应影响。低速保持航向，5厘米跟踪位置误差不再触发转向；移动方向超出机头正前方±60度仍按原规则悬停转向。

## 本轮证据

源码/编译日志/实际界面截图与进程记录在 `start/qt_work/20261004_xy_navigation`。只编译、启动界面及路径节点，不进行飞行/故障验收；交互与路线尚未通过在线飞行复测。原EKF96ms融合瞬态降落问题保持待诊断，不因界面修改判修复。

## 地图更新与任务结束

- EGO地图快照只在新的观测被纳入后发布一次，并保留该观测采集时间；latched快照支持后加入的订阅者，旧快照不能刷新健康。
- 管理器与黄线路径节点拒绝重复/旧时间戳；新的时间戳对应相同地图字节和布局时复用体素编码，正常更新采集时间判定。缓存每类地图只保留一份。
- 黄线路径节点无目标时不进行体素转换或A*；新目标清空旧任务地图，等待新地图，再执行完整安全检查。
- 导航结束（含到达、取消或保护退出）清除红色目标、黄色路径和绿色轨迹；晚到的旧路径不能恢复已经结束任务的覆盖层。HOLD且健康允许时恢复点选。

## 规划节点重启

管理器只用新鲜原始Bspline跟踪轨迹编号；旧PositionCommand不能提高下一目标的编号门槛。源曲线编号下降时取消当前导航至HOLD，需重新选择目标；异步验证使用独立递增任务代次。轨迹发布器导航禁用即清空旧曲线，规划链路应整体重启。黄线路径使用/drone/fcu/odom，保持与规划点云相同的FCU ENU数值坐标。

## 航向来源（2026-10-04修复）

航向判断采用执行器审批局部Bspline沿递增参数的一阶导数在ENU XY平面的方向。每条新曲线起步/首次对齐阶段约向前10cm弧长取切线，避免零初始切线；正常运动取当前执行参数处切线，退化/纯竖直/结束保持当前航向。EGO静止起步（<=0.1m/s）采用零速度边界，避免估计残速折弯初始路线；不改变IMU速度估计、EKF融合或运动中的重规划连续性。无审批曲线时保持悬停重试，不按目标直线自行转向。±60度超界悬停转向规则保持。

## 转向结束与规划恢复（2026-10-04）

- 保留实际航向误差<=10度、速度<=0.1m/s、定位健康、稳定0.3秒以及稳定后新扫描的条件。删除额外0.25秒话题延时；Qt导航提示显示是在等稳定、新扫描还是规划确认。
- `/planning/start` 在规划器回调中一起设置目标、速度、当前里程计起点与会话代次，清除旧局部曲线及全局参考中的旧局部拼接；返回确认后执行器才发布启用。服务调用由后台串行线程完成，等待期间持续发送悬停指令。取消或转向会使晚到的旧确认失效。
- 碰撞重规划仅允许在当前有效EXEC_TRAJ/REPLAN_TRAJ曲线上运行；INIT、等待目标或首次生成阶段不能从旧曲线恢复。新会话首次曲线起点距当前机体超过0.25m时拒绝执行并悬停重规划；已有0.75m指令位置跳变保护保留。
- 黄线搜索按每批约25ms线程CPU时间续算，保留搜索队列。转向/等待期间不用停下的旧EGO曲线时间推进路线；每轮按最新占用地图重验已显示路径。出现障碍只保留与当前点相连的有效前段，完整新路线通过最新地图后一次替换。地图、位姿或时钟失效时仍撤销黄线。
- 本轮构建、回归及飞行记录在 `start/qt_work/manual_monitor_20261004_planning_resume`；实际飞行结论以该目录 `flight_result.json` 和 `CHANGES.md` 为准。

## 统一全局路线（2026-10-04后续修改）

实际链路为：管理器接受目标 → `/drone/navigation_goal` → 全局3D A* → `/drone/global_route` → EGO局部目标/B样条优化 → 执行器安全审批 → 飞控。`/drone/global_path`和黄色Marker与GlobalRoute中的Path同源发布。

全局A*不再反向消费EGO原始候选曲线。管理器后台等待同任务、新鲜且到达最终目标的完整路线，将它随`/planning/start`一起交给EGO；等待时持续悬停。EGO按全局折线选择局部终点，在明显拐点前停止该段目标，避免把绕行折线直接连成穿障碍的弦；运动中接收同任务完整路线更新。EGO独立的起点到最终目标多项式全局参考在本项目中关闭，内部A*和B样条仍用于局部调整。局部段结束而最终目标未到达时继续规划后续段。

路线有独立任务ID，不使用ROS会自动改写的Header.seq；取消、换目标、转向与重试的任务/会话验证保留。部分路线可以显示安全前段，但不能作为完整路线确认；路线过期时禁止生成新的局部目标。未知空间的执行审批及所有定位、OFFBOARD保护保持。

记录在 `start/qt_work/manual_monitor_20261004_unified_route`；飞行验证结论以该目录结果为准。
